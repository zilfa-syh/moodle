# 👨‍🏫 Panduan Moodle untuk GURU

Panduan ini membantu Bapak/Ibu Guru dalam mengelola kelas, memberikan materi, dan menilai siswa di Moodle SMKN 5 Telkom Banda Aceh.

## 1. Memulai Mode Edit
Untuk menambahkan atau mengubah materi, Anda **wajib** menyalakan Mode Edit.
1. Masuk ke mata pelajaran Anda.
2. Di pojok kanan atas, klik tombol/switch **Mode Edit** (Turn editing on) hingga berwarna aktif.

## 2. Menambahkan Materi Pelajaran
1. Pastikan Mode Edit **menyala**.
2. Di bawah nama Topik/Bab, klik tulisan **+ Tambahkan aktivitas atau sumber** (Add an activity or resource).
3. Pilih jenis materi:
   - **Page (Halaman)**: Untuk mengetik materi langsung beserta gambar/video.
   - **File**: Untuk mengunggah dokumen PDF/Word/PPT.
   - **URL**: Untuk menyematkan link artikel atau video YouTube.

## 3. Membuat Tugas (Assignment)
1. Klik **+ Tambahkan aktivitas atau sumber**.
2. Pilih **Tugas** (Assignment).
3. Isi **Nama Tugas** dan **Deskripsi** (instruksi tugas).
4. Pada bagian *Availability* (Ketersediaan), atur tenggat waktu (Deadline).
5. Pada bagian *Submission types*, pilih apakah siswa harus mengunggah file (File submissions) atau mengetik langsung (Online text).
6. Klik **Simpan dan tampilkan**.

## 4. Menilai Tugas Siswa
1. Klik tugas yang telah Anda buat.
2. Klik tombol **Lihat semua kiriman** (View all submissions) untuk melihat daftar siswa yang sudah mengumpulkan.
3. Klik tombol **Nilai** (Grade) pada baris nama siswa.
4. Masukkan angka nilai dan berikan komentar (Feedback).
5. Klik **Simpan perubahan**.

## 5. Membuat Kuis / Ulangan
1. Klik **+ Tambahkan aktivitas atau sumber** -> Pilih **Kuis** (Quiz).
2. Beri nama kuis dan atur waktu pengerjaan di menu *Timing*. Klik **Simpan dan tampilkan**.
3. Di halaman Kuis yang masih kosong, klik **Tambahkan soal** (Edit quiz).
4. Klik tombol **Tambah** (Add) di sebelah kanan, pilih **Sebuah soal baru** (a new question).
5. Pilih tipe soal (Pilihan Ganda / Benar-Salah / Essay) dan isi pertanyaan serta kunci jawaban.
