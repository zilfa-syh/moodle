# 📘 BUKU PANDUAN LENGKAP E-LEARNING MOODLE
**SMKN 5 TELKOM BANDA ACEH**

Sistem e-Learning Moodle memiliki tingkatan peran (role) yang berbeda. Dokumen ini merangkum seluruh panduan secara detail untuk masing-masing peran, mulai dari Siswa hingga Administrator.

---

## 👨‍🎓 BAB 1: PANDUAN SISWA (STUDENT)
Siswa adalah pengguna yang bertugas membaca materi, berdiskusi, mengirimkan tugas, dan mengerjakan ujian.

### 1.1 Cara Login ke Sistem
1. Buka aplikasi browser (Chrome/Firefox/Safari) di HP atau Laptop.
2. Kunjungi alamat: **https://moodle.xorbit.my.id**
3. Klik tombol **Masuk** (Log In) di kanan atas atau masukkan data di form sebelah kanan.
4. Masukkan **Username** (NIS / Username yang diberikan sekolah).
5. Masukkan **Password** (Perhatikan huruf besar, kecil, dan simbol).
6. Jika ini pertama kali Anda login, sistem mungkin akan meminta Anda untuk mengganti password baru.

### 1.2 Navigasi Beranda dan Kursus
- **Dasbor (Dashboard)**: Menampilkan kursus yang sedang Anda ikuti beserta progres penyelesaian (persentase) dan tugas yang akan datang (Timeline).
- **Kursusku (My Courses)**: Menampilkan daftar seluruh mata pelajaran Anda.
- Klik pada nama/gambar mata pelajaran untuk masuk ke dalamnya.

### 1.3 Cara Membaca Materi Pelajaran
1. Masuk ke mata pelajaran.
2. Anda akan melihat materi yang disusun berdasarkan **Bab/Topik**.
3. Ikon **Kertas/Buku (Page/Book)**: Klik untuk membaca teks materi langsung di web.
4. Ikon **File (PDF/Word/PPT)**: Klik untuk mendownload dan menyimpan dokumen ke perangkat.
5. Ikon **Rantai (URL)**: Klik untuk diarahkan ke video YouTube atau website rujukan luar.

### 1.4 Cara Mengerjakan dan Mengirim Tugas (Assignment)
1. Cari aktivitas dengan **ikon tangan memegang kertas**.
2. Klik nama tugas tersebut dan baca instruksi dari guru dengan teliti.
3. Di bagian paling bawah, klik tombol **Tambahkan pengajuan tugas (Add submission)**.
4. Ada dua jenis tugas:
   - **Teks Daring (Online Text)**: Ketik jawaban Anda langsung di dalam kotak teks yang disediakan.
   - **Unggah File**: Klik ikon panah ke bawah, pilih `Upload a file`, cari file jawaban Anda (PDF/Word/Foto), lalu klik `Upload this file`.
5. Klik **Simpan perubahan (Save changes)**.
6. Pastikan Status Pengumpulan berubah menjadi warna hijau: **"Dikumpulkan untuk dinilai"**.

### 1.5 Cara Mengerjakan Kuis / Ujian Tengah Semester
1. Cari aktivitas dengan **ikon lembar kertas dengan tanda centang merah**.
2. Klik tombol **Mencoba kuis sekarang (Attempt quiz now)**.
3. Kerjakan soal dengan teliti. Di sebelah kanan ada "Navigasi kuis" untuk melompat antar soal.
4. Jika sudah di nomor terakhir, klik **Selesaikan kuis (Finish attempt)**.
5. Periksa ringkasan jawaban. Jika sudah yakin, klik **Kirim semua dan selesai (Submit all and finish)**.
6. Anda mungkin bisa langsung melihat nilai Anda (tergantung pengaturan guru).

## 👨‍🏫 BAB 2: PANDUAN GURU (TEACHER / EDITING TEACHER)
Guru memiliki wewenang untuk mengisi konten di dalam kursusnya, membuat kuis, dan memberi nilai.

### 2.1 Mengaktifkan Mode Edit (Sangat Penting)
Untuk dapat mengubah susunan mata pelajaran atau menambahkan modul:
1. Masuk ke mata pelajaran Anda.
2. Di pojok kanan atas, temukan tombol switch/toggle **Mode Edit (Turn editing on)**.
3. Klik hingga berubah warna menjadi aktif (Oranye/Hijau). Menu tambah aktivitas akan langsung muncul di bawah setiap topik.

### 2.2 Menambah Materi (Resource)
1. Pastikan Mode Edit aktif.
2. Klik tombol **+ Tambahkan aktivitas atau sumber (Add an activity or resource)**.
3. **Membuat Halaman Materi (Page)**:
   - Pilih "Halaman (Page)".
   - Isi Nama halaman.
   - Di kotak "Isi halaman (Page content)", ketik materi Anda. Anda juga bisa menyisipkan gambar dan video. Simpan.
4. **Mengunggah File Presentasi/PDF (File)**:
   - Pilih "File".
   - Isi Nama File.
   - Drag-and-drop (seret dan lepas) file PDF/PPT Anda ke dalam kotak "Pilih file". Simpan.

### 2.3 Membuat Tugas / PR (Assignment)
1. Klik **+ Tambahkan aktivitas atau sumber**.
2. Pilih **Tugas (Assignment)**.
3. Isi **Nama Tugas** dan **Instruksi** pada kotak Deskripsi.
4. Atur rentang waktu pengumpulan di menu **Ketersediaan (Availability)**:
   - *Izinkan kiriman dari*: Tanggal tugas mulai dibuka.
   - *Batas waktu*: Tenggat pengumpulan (Deadline utama).
5. Di menu **Tipe Pengajuan (Submission types)**:
   - Centang "Pengiriman berkas" jika siswa harus upload file.
   - Centang "Teks daring" jika siswa mengetik di web.
6. Klik **Simpan dan tampilkan**.

### 2.4 Memeriksa dan Menilai Tugas
1. Klik nama tugas yang sudah dikerjakan siswa.
2. Klik **Lihat semua kiriman (View all submissions)** untuk melihat tabel daftar siswa.
3. Klik tombol **Nilai (Grade)** di sebelah nama siswa.
4. Di panel kanan, masukkan nilai (contoh: 85) di kotak Grade.
5. Masukkan komentar perbaikan di kotak Feedback.
6. Klik **Simpan dan perlihatkan selanjutnya** untuk menilai siswa berikutnya.

### 2.5 Membuat Ulangan Harian (Quiz)
Pembuatan kuis terdiri dari 2 tahap: Membuat cangkang kuis, lalu memasukkan soal.
**Tahap 1: Cangkang Kuis**
1. Klik **+ Tambahkan aktivitas atau sumber** -> Pilih **Kuis (Quiz)**.
2. Isi Nama Kuis.
3. Buka tab **Waktu (Timing)**. Aktifkan *Kuis dibuka* dan *Kuis ditutup*. Atur *Waktu pengerjaan (Time limit)* (misal: 60 menit).
4. Klik **Simpan dan tampilkan**.

**Tahap 2: Memasukkan Soal**
1. Di dalam halaman Kuis yang masih kosong, klik **Tambahkan soal (Edit quiz)**.
2. Di sebelah kanan, ketik nilai maksimal (misal: 100), lalu klik Simpan.
3. Klik tulisan **Tambah (Add)** -> **Sebuah soal baru (A new question)**.
4. Pilih "Pilihan Ganda" atau "Esai".
5. Isi Pertanyaan, lalu isi pilihan jawaban (Pilihan 1, 2, dst).
6. Untuk jawaban yang BENAR, ubah kolom "Nilai (Grade)" menjadi **100%**. Untuk yang salah, biarkan None.
7. Simpan perubahan.

## 🛠️ BAB 3: PANDUAN COURSE CREATOR
Course creator bertanggung jawab merancang kerangka awal kursus dan mendaftarkan guru, tanpa perlu mengisi kontennya.

### 3.1 Membuat Mata Pelajaran (Course) Baru
1. Buka menu navigasi kiri -> **Administrasi Situs (Site administration)**.
2. Pilih tab **Kursus (Courses)** -> **Kelola kursus dan kategori (Manage courses and categories)**.
3. Klik Kategori / Jurusan yang tepat di panel kiri (misalnya: X RPL).
4. Di panel kanan, klik tombol **Buat kursus baru (Create new course)**.
5. Lengkapi formulir:
   - **Nama lengkap kursus**: Tampil besar di halaman (Misal: Pemrograman Dasar X RPL).
   - **Nama singkat kursus**: Kode unik untuk sistem (Misal: PROGDAS-X-RPL).
   - **Kategori kursus**: Pastikan sudah benar.
   - **Visibilitas kursus**: Tampilkan.
6. Buka bagian **Format kursus**:
   - Pilih *Format topik (Topics format)*.
7. Klik **Simpan dan tampilkan**.

### 3.2 Menugaskan Guru ke Kursus
Sistem tidak otomatis tahu siapa guru untuk pelajaran tersebut. Anda harus menugaskannya (Assign Role).
1. Masuk ke dalam mata pelajaran yang baru Anda buat.
2. Di bagian atas, klik tab **Peserta (Participants)**.
3. Klik tombol **Daftarkan pengguna (Enroll users)** di pojok kanan.
4. Di jendela yang muncul:
   - *Select users*: Ketik nama atau email Bapak/Ibu Guru.
   - *Tetapkan peran (Assign role)*: Ganti dari Siswa menjadi **Pengajar (Teacher)**.
5. Klik **Daftarkan pengguna**.
*(Tugas Anda selesai, guru tersebut sekarang bisa masuk dan mulai menyalakan mode edit).*

## 🏢 BAB 4: PANDUAN ADMINISTRATOR / MANAGER
Admin dan Manager memegang kendali penuh operasional sekolah. Mereka mengurus data ribuan siswa, pembagian kelas, laporan sistem, dan pengaturan tema (tampilan).

### 4.1 Manajemen Kelas (Kohort / Cohort)
Moodle tidak memakai istilah "Kelas" untuk rombongan belajar, melainkan **Kohort**.
1. **Membuat Kohort**:
   - Administrasi Situs -> Pengguna -> Akun -> **Kohort (Cohorts)**.
   - Klik tab **Tambah kohort baru**.
   - Isi Nama (Misal: X TKJ 1) dan ID Kohort (Misal: x-tkj-1). Simpan.
2. **Memasukkan Siswa ke Kohort secara manual**:
   - Di daftar Kohort, klik ikon gambar **Orang/Assign**.
   - Cari siswa di kotak kanan (Potential users), pilih, dan klik tombol **Tambah (<)** untuk memindahkannya ke kotak kiri (Current users).

### 4.2 Import Pengguna Massal via CSV
Ini adalah cara tercepat untuk memasukkan 500 siswa sekaligus tanpa pendaftaran manual.
1. Siapkan data Excel, lalu simpan dalam format **CSV (Comma Delimited)**. Format Kolom Header wajib:
   `username,password,firstname,lastname,email,cohort1`
   *(Catatan: Isian cohort1 harus sama persis dengan ID Kohort yang Anda buat di poin 4.1. Jika ID kohort belum ada, sistem akan membuat kohort baru otomatis).*
2. Buka **Administrasi Situs** -> **Pengguna** -> **Unggah pengguna (Upload users)**.
3. Masukkan file CSV. Pisahkan dengan "koma". Klik Unggah.
4. **PENGATURAN PENTING DI HALAMAN PREVIEW**:
   - *Tipe unggahan (Upload type)*: **Add new only, skip existing** (Agar data lama tidak tertimpa).
   - *Kata sandi pengguna baru*: **Field required in file** (Gunakan password dari Excel).
   - *Paksa perubahan kata sandi*: **Semua / Pengguna dengan password lemah** (Agar siswa ganti sandi saat login).
5. Klik **Unggah pengguna**.

### 4.3 Sinkronisasi Kelas ke Mata Pelajaran (Cohort Sync)
Daripada memasukkan siswa satu per satu ke dalam Kursus, gunakan Cohort Sync. Jika ada anak baru masuk ke Kohort, ia akan otomatis masuk ke semua mata pelajarannya.
1. Masuk ke mata pelajaran.
2. Klik tab **Peserta (Participants)**.
3. Klik tombol dropdown (tanda panah) di sudut kiri atas area Peserta, pilih **Metode pendaftaran (Enrollment methods)**.
4. Di bagian *Tambahkan metode*, pilih **Sinkronisasi kohort (Cohort sync)**.
5. Formulir akan muncul:
   - Pilih nama kohort (Misal: X TKJ 1).
   - Peran (Role): Siswa.
6. Klik **Tambah metode**. Ratusan siswa akan langsung masuk ke kursus dalam hitungan detik.

### 4.4 Kustomisasi Tampilan (Tema Moove)
1. Buka **Administrasi Situs** -> **Penampilan (Appearance)** -> **Tema (Themes)** -> **Moove**.
2. **Tab General**: Anda bisa mengunggah Logo sekolah dan Favicon (ikon kecil di tab browser).
3. **Tab Frontpage**: Anda bisa mengatur gambar slider, teks promosi/marketing, dan angka statistik halaman depan.
4. **Tab Advanced (Raw SCSS)**: Kotak paling bawah digunakan untuk menyuntikkan kode CSS kustom jika Anda butuh modifikasi tampilan khusus (seperti membesarkan logo atau mengganti warna background login).
5. **Setiap kali mengubah tampilan atau pengaturan utama, Anda WAJIB MENGHAPUS CACHE**:
   - Administrasi Situs -> Pengembangan (Development) -> **Bersihkan semua cache (Purge caches)**.

### 4.5 Backup / Pencadangan Server
Untuk keamanan data jangka panjang, Anda bisa membuat pencadangan dari Moodle, atau menggunakan script otomatis di server.
- **Backup Manual Mata Pelajaran**:
  1. Masuk ke kursus, klik ikon Lanjut (Lebih banyak) -> **Gunakan kembali kursus (Course reuse)**.
  2. Pilih menu dropdown menjadi **Cadangkan (Backup)**. Ikuti proses (Next, Next, Perform Backup).
  3. File `.mbz` bisa didownload.
- **Backup Level Server**: Server saat ini sudah dilengkapi bash script (`/root/moodle/backup.sh`) yang mem-backup database, file kode, dan data media (moodledata). Hasilnya tersimpan di `/root/moodle-backups/` dan berjalan otomatis (Cron job) setiap jam 02:30 pagi.
